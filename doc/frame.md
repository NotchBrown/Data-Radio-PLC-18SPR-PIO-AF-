# 帧结构（分层）

本文档按**分层**讲清无线帧协议：**超帧(UF) → 帧(F) → 内容**。
超帧负责无线信道特有的字段（如同步字、地址、校验）；帧负责应用数据（定位头 + 内容指示 + 内容）。

## 分层总览

```
┌────────────────────────────────────────────────────────┐
│ 超帧 UF（无线信道层）                                   │
│   [前导][同步字][长度][地址][帧(F)][CRC]                │
│         └ 长度：SX1278 显式头报头（先于净负荷）         │
│         └ 地址：逻辑上属超帧（信道层字段）               │
│           SX1278 无硬件地址 → 软件实现其字节             │
│           （置于净负荷第一字节、长度之后、帧之前）        │
└────────────────────────────────────────────────────────┘

帧 F（帧本身不含地址）：
  [定位头|内容指示][内容...]
     ├ 内容指示=0 → 遥测：内容指示字节 + 可变数据
     └ 内容指示=1 → 内容字节 MSB：0=命令 / 1=RS-485
```

## 第 1 层：超帧（UF，无线信道层）

结构：`[前导码][同步字][负荷长度][地址][帧][CRC]`

| 段 | 生成者 | 说明 |
|----|--------|------|
| 前导码 | SX1278 | 接收同步用 |
| 同步字 | SX1278 | SyncWord（0x39 配置），无线信道特有 |
| **负荷长度** | SX1278 | 显式头报头（发送时自动填实际长度，先于净负荷） |
| **地址** | **软件实现，逻辑上属超帧** | SX1278 无硬件地址，软件实现其字节（置于净负荷第一字节、长度之后、帧之前）；接收端过滤 self/0xFF 广播 |
| 帧 | 软件 | 应用数据（见第 2 层） |
| CRC | SX1278 | 校验 |

> 超帧负责无线信道特有的字段（如同步字）+ 地址 + 帧 + 校验。
> **地址虽由软件实现（SX1278 无硬件地址），但从逻辑上属于超帧，不属于帧。**

## 第 2 层：帧（F）

结构：`[定位头|内容指示][内容...]`

```
帧 Byte0 = 定位头(7bit 0b0011011) | 内容指示(1bit)
           └ 定位头 0011011：帧起始标识
           └ 内容指示：0=遥测，1=命令/485
帧 Byte1.. = 内容（由内容指示决定，见第 3 层）
```

> 帧本身不含地址（地址在超帧层）。

## 第 3 层：内容（按内容指示）

### 内容指示 = 0：遥测帧

**主站 → 从站**：`[定位头|0][内容指示字节1][内容指示字节2][可变数据]`
- **内容指示字节1（CI₁）**：主站本次发送的内容指示（主站→从站传哪些数据）
- **内容指示字节2（CI₂）**：主站**要求从站回传时**用的内容指示
- 可变数据：按 **CI₁** 编码（编码见下"遥测净负荷编码"）

**从站 → 主站**：`[定位头|0][内容指示字节][可变数据]`
- **内容指示字节**：从站实际回传的内容指示（= 主站要求的 **CI₂**），**仍是 1 个字节**
- 可变数据：按该内容指示编码

> 主站一发帧同时**告诉从站"你回传时发哪些通道"**；从站按此要求组织回传。

### 内容指示 = 1：命令 / 485 帧
`[定位头|1][内容字节][...]`，内容字节 **MSB** 决定类型：

| MSB | 类型 | 格式 | 帧长 |
|-----|------|------|------|
| 0 | 电台命令 | `0 CCCCCCC`（7bit 命令码，仅服务无线通信） | 3 字节（地址+帧2） |
| 1 | RS-485 数据 | `1 LLLLLLL`（长度 0~127）+ 数据×L | 3+L 字节 |

> 命令帧：`[地址][0b00110111][0 CCCCCCC]`
> 485 帧 ：`[地址][0b00110111][1 LLLLLLL][RS-485 数据 × L]`

## 字节布局汇总

| 净负荷字节 | 遥测-主站→从站(指示=0) | 遥测-从站→主站(指示=0) | 命令(指示=1, MSB=0) | 485(指示=1, MSB=1) |
|:---:|:---:|:---:|:---:|:---:|
| 0 | 地址（属超帧） | 地址（属超帧） | 地址（属超帧） | 地址（属超帧） |
| 1 | 0x36（定位头\|0） | 0x36（定位头\|0） | 0x37（定位头\|1） | 0x37（定位头\|1） |
| 2 | **CI₁**（主站发） | CI（回传实际） | 0 CCCCCCC | 1 LLLLLLL |
| 3 | **CI₂**（要求从站回传） | 可变数据 | — | RS-485 数据 × L |
| 4.. | 可变数据（按 CI₁） | — | — | — |

## 遥测净负荷编码（内容指示字节）
第一字节：内容指示，从高到低：DH、DL、A3、A2、A1、A0、字长比特、压缩比特
1. 前六个比特用于指示所对应的内容是否在下面的可变字节区内，而且下面的内容按顺序排好，例如当101011XX的时候，说明下面依次有D15~D8、A3、A1、A0的数据
2. 后两个比特指示模拟信号是如何发送的，字长比特为1说明是10比特/模拟通路，为0说明是8比特/模拟通路，压缩比特则指示是否采用A-13折线压缩
3. 当字长比特为0，压缩比特为1的时候说明此时后面的A的数据采用A-13折线压缩，当字长比特为0，压缩比特为0的时候说明此时后面的A的数据采用截断压缩
4. 当字长比特为1，压缩比特为1的时候，这种情况是不允许存在的
5. 当字长比特为1，压缩比特为0的时候，此时传输由于不能占满字节，则采用高端对齐，低端补0，此时传输一路模拟占用16比特，传输两路是24比特，传输三路是32比特，传输四路则刚好对齐，是40比特，这种方法需要注意位移解包和打包
6. DH就是被传输机器的D15~D8，DL就是D7~D0，A同理
7. A-13是标准的，如果输入精度不够，左移补齐

## 注记
1. 地址逻辑上位于超帧的地址段（前导+同步+长度+地址+帧+CRC），**属于超帧层**。
   SX1278 无硬件地址，故软件实现其字节：所有帧（遥测/命令/485）净负荷第一字节 = 地址
   （在长度之后、帧之前），帧本身不含地址；接收端过滤 self/0xFF 广播。

## RF 收发模式（统一异步主从；角色见 upperpc.md 0x19，与拨码无关）
取消原 4 种收发模式，统一为"主从异步"：
- **主机**：按发射表周期发送遥测帧（每帧含 **CI₁** 本机内容 + **CI₂** 要求从站回传）；
  等从站回传，超时重传，连续失败回握手重建链路
- **从机**：收到主站帧，按主站要求的 **CI₂** 组织本机数据回传（回传帧为 1 个 CI）
- 掉线重连：3s 无有效帧 -> 回握手（link_try）；5s 仍无 -> SYS LED(PH1) 常亮报警
