# 上位机可配置项总览（UART3 配置接口）

> 用途：上位机（PC）开发配置清单。基于 `upperpc.md` 整理，按功能分组，便于快速查阅。
> 接口：UART3（CH340N，115200 8N1）。**读帧头 `0x36`，写帧头 `0x37`。**
> 完整帧格式与状态机见 `upperpc.md`；本文件只列"可配置/可读写"项。

## 1. 通信帧（速览）

```
[帧头][地址码][数据码 2B 小端][CRC-8][帧尾]
 读: 0x36        写: 0x37    (读时数据为 0)
CRC-8: 多项式 0x07，初始 0x00，覆盖 帧头~数据码
帧尾: 帧头的按比特非（读 0x36→0xC9，写 0x37→0xC8）
回复: 对称帧；写入回"设定后数值"，读取回"该地址数值"
```
- 地址码 0~255，数据码 16bit **小端序**（高位不足补 0）。
- 写后立即生效的项，需 `0x1E` 写 0x0001 才存 EEPROM（见 §6）。

## 2. 系统 / 标识

| 地址 | 名称 | 读写 | 说明 |
|:---:|------|:---:|------|
| 0x00~0x02 | MCU ID | 只读 | 6 字节（每地址 2 字节小端） |
| 0x03 | RTC 毫秒 | 读写 | 16bit |
| 0x04~0x09 | RTC 秒/分/时/日/月/年 | 读写 | 各低 8bit |

## 3. 实时数据（只读）

| 地址 | 名称 | 说明 |
|:---:|------|------|
| 0x0A | DI7~0 | 低 8bit |
| 0x0B | DI15~8 | 16bit 数据字低 8 位（DI 高 8 路） |
| 0x0C | DO7~0 | 写=设输出（低有效） |
| 0x0D | DO15~8 | 写=设输出（低有效） |
| 0x0E~0x11 | AI0~3 | 10bit 模拟输入，16bit |
| 0x12~0x15 | AO0~3 | 10bit 模拟输出，16bit；写=设 DAC |

## 4. 网络 / 角色

| 地址 | 名称 | 读写 | 说明 | 存 EEPROM |
|:---:|------|:---:|------|:---:|
| 0x16 | 本机 RF 地址 | 读写 | 8bit 低有效 | ✅ |
| 0x17 | 对端 RF 地址 | 读写 | 8bit 低有效 | ✅ |
| 0x18 | 收发模式 | 固定 0 | 统一异步主从，原 4 模式取消 | ✅ |
| 0x19 | 主从位 | 读写 | 0=从机 1=主机 | ✅ |

## 5. RF 参数（SX1278）

| 地址 | 名称 | 典型值 | 说明 | 存 EEPROM |
|:---:|------|:---:|------|:---:|
| 0x30/0x31 | 载波频率 | 433/470MHz | 低16 + 高16 组 32bit(Hz) | ✅ |
| 0x32 | 扩频因子 SF | 6~12 | 空速自动算 | ✅ |
| 0x33 | 带宽 BW | 125/250/500 | kHz | ✅ |
| 0x34 | 编码率 CR | 5~8 | 即 4/5~4/8 | ✅ |
| 0x35 | 发射功率 | 由芯片 | dBm | ✅ |
| 0x36 | 前导码长度 | — | | ✅ |
| 0x37 | 同步字 | — | | ✅ |
| 0x38 | LNA 增益 | — | | ✅ |

> 0x30~0x38 上电按此配置 SX1278（自动算寄存器）。

## 6. 存储命令

| 地址 | 操作 | 说明 |
|:---:|------|------|
| 0x1E | 写 0x0001 | **保存当前配置到 EEPROM**，回 0x0001=成功/0x0000=失败 |
| 0x1E | 读 | 回配置区有效性：0x0001=已保存有效 / 0x0000=无效 |
| 0x1F | 写 0x0001 | **恢复出厂**（清除 EEPROM 配置区），回 0x0001 |
| 0x1F | 读 | 回 0x0000 |

> ⚠️ **保存是阻塞操作**（EEPROM 逐字节编程约数百 ms），期间 UART3 收帧暂缓，上位机应**等回复后再发下一条**。

## 8. 发射任务表（32 任务，0~31）

| 地址区 | 内容 | 说明 |
|:---:|------|------|
| 0x80 + 任务×4 + 0 | **CI₁** 发射内容指示 | 主站→从站传什么 |
| 0x80 + 任务×4 + 1 | **ENA** | bit0=1 启用 / 0 禁用 |
| 0x80 + 任务×4 + 2 | 周期 低16bit | 小端序，单位= TIM4 6kHz 节拍(166.7us)，6tick=1ms |
| 0x80 + 任务×4 + 3 | 周期 高16bit | 小端序，单位= TIM4 6kHz 节拍(166.7us)，6tick=1ms |
| **0x40 + 任务** | **CI₂** 从站回传内容指示 | 要求从站回传什么 |

> 地址计算：任务 N 的参数 k（0~3）= `0x80 + N*4 + k`。
> CI₂ 用独立地址 `0x40 + N`（0x40~0x5F），与发射参数分开。

## 上位机开发注意事项

### 参数生效生命周期（必读）

参数"写入"到"真正影响硬件"分两层：

| 层 | 说明 |
|----|------|
| **RAM 变量** | 写命令立即改（掉电丢失） |
| **EEPROM** | `0x1E` 保存才持久；上电 `uart3_config_restore` 回填 |

写硬件时机分 **3 类**：

| 类 | 参数 | 生效时机 |
|:--:|------|------|
| **A 立即** | DO/AO/RTC/地址角色 | 写命令即驱动硬件 |
| **B 下轮** | 发射任务表(CI₁/ENA/周期/CI₂) | 主循环调度立即读，下轮发射生效 |
| **C 需重配** | RF 参数(0x30~0x38) / 485参数(0x1A~0x1D) | 只改 RAM，需重配才写硬件 |

C 类的重配时机：
- **RF 参数**：上电 / 模式2/3 切换 / **`0x29` 写 0x0001（立即生效）**
- **485 参数**：仅上电 `uart1_init`（暂不支持运行时重配）

**推荐上位机流程**：`写参数 → (RF 参数可发 0x29 立即生效) → 0x1E 保存`

### 帧结构/注意事项

1. **小端序**：所有 16bit 数据码低字节在前。
2. **写后须保存**：改配置后发 `0x1E`+`0x0001` 才写入 EEPROM；不保存则掉电丢失。
3. **保存阻塞**：`0x1E` 后必须等回复，再发下一条。
4. **只读模式拦截**：0x1E/0x1F 在只读模式被拦截（自动转读）——具体见 `mode1.c`/固件逻辑。
5. **CRC-8**：多项式 0x07，初始 0x00，覆盖帧头~数据码；尾 = 帧头按位非。
6. **频偏校正**：0x26 触发需先 0x28=1；0x27 存 EEPROM。
7. **EEPROM 布局**：265 字节（v0.06），CRC-8 在偏移 264。详见 `upperpc.md` 末尾表格。

## 推荐上位机默认流程

```
1. 读 0x1E  → 判断是否已保存配置（有效才继续）
2. 读 0x16/0x17/0x19 → 网络与角色
3. 读 0x30~0x38 → RF 参数
4. 读 0x40~0x5F、0x80~0xFF → 发射任务表 + CI₂
5. 读 0x1A~0x1D → 485 配置
6. 修改 → 写地址 → 0x1E 保存
```
