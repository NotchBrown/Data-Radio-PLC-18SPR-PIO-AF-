# 上位机帧结构
## 帧结构
帧定位头+地址码+数据码+CRC-8+帧定位尾
> 帧定位头 00110111：帧用于写入，00110110：帧用于读取
> 地址码共256个地址，详见地址表
> 数据码，双字（2字节，16bit），小端序，不足16bit高位补0
> CRC-8（多项式0x07，初始0x00，覆盖帧定位头~数据码）
> 帧定位尾是帧定位头的按比特非
## 注记
1. 帧结构是对称的，也就是说回复也是这种帧结构
2. 写入的时候回复帧为设定之后的数值，读取的时候发送帧的数据为0
## 状态机（UART3 帧收发）
接收：IDLE → HEAD → ADDR → DATA(2B) → CRC → TAIL → DONE
- IDLE：等帧定位头（0x37 写入 / 0x36 读取）
- HEAD：已收定位头，收地址码
- ADDR：收数据码2字节（小端序）
- DATA：收CRC-8
- CRC：收帧定位尾（定位头按位非）
- TAIL→DONE：校验地址合法、CRC匹配、尾匹配，通过则执行并回复，回IDLE
- 任一字节不匹配或字节间隔超时 → 回IDLE
回复（对称帧）：写入回设定后的数值，读取回该地址数值
## 地址表
00000000~00000010：MCU ID（6字节，每地址2字节小端序）
00000011：RTC 毫秒（16bit）
00000100：RTC 秒（低8bit）
00000101：RTC 分（低8bit）
00000110：RTC 时（低8bit）
00000111：RTC 日（低8bit）
00001000：RTC 月（低8bit）
00001001：RTC 年（低8bit）
00001010：DI7~0（低8bit）
00001011：DI15~8（低8bit）
00001100：DO7~0（低8bit）
00001101：DO15~8（低8bit）
00001110：AI0（16bit）
00001111：AI1（16bit）
00010000：AI2（16bit）
00010001：AI3（16bit）
00010010：AO0（16bit）
00010011：AO1（16bit）
00010100：AO2（16bit）
00010101：AO3（16bit）
01000000~01111111：射频设置字段
  低6位 = SX1278寄存器号（0x00~0x3F），值放低字节
10000000~11111111：发射流程设置字段
  bit7 = 1
  bit6:2 = 任务编号（0~31）
  bit1:0 = 参数地址
  参数0（00）：发射内容 = 帧内容指示字段（低字节）
  参数1（01）：任务 ENA（bit0 = 1 启用，0 禁用）
  参数2（10）：执行周期 低16bit（小端序，单位128us）
  参数3（11）：执行周期 高16bit（小端序，单位128us）
