# 上位机帧结构
## 帧结构
帧定位头+地址码+数据码+CRC-8+帧定位尾
> 帧定位头 00110111：帧用于写入，00110110：帧用于读取
> 地址码共256个地址，详见地址表
> 数据码，双字（2字节，16bit），小端序，不足16bit高位补0
> CRC-8（多项式0x07，初始0x00，覆盖帧定位头~数据码）
> 帧定位尾是帧定位头的按比特非
## 注记
1. 帧结构是对称的，也就是说回复也是这种帧结构
2. 写入的时候回复帧为设定之后的数值，读取的时候发送帧的数据为0
## 状态机（UART3 帧收发）
接收：IDLE → HEAD → ADDR → DATA(2B) → CRC → TAIL → DONE
- IDLE：等帧定位头（0x37 写入 / 0x36 读取）
- HEAD：已收定位头，收地址码
- ADDR：收数据码2字节（小端序）
- DATA：收CRC-8
- CRC：收帧定位尾（定位头按位非）
- TAIL→DONE：校验地址合法、CRC匹配、尾匹配，通过则执行并回复，回IDLE
- 任一字节不匹配或字节间隔超时 → 回IDLE
回复（对称帧）：写入回设定后的数值，读取回该地址数值
## 地址表
00000000~00000010：MCU ID（6字节，每地址2字节小端序）
00000011：RTC 毫秒（16bit）
00000100：RTC 秒（低8bit）
00000101：RTC 分（低8bit）
00000110：RTC 时（低8bit）
00000111：RTC 日（低8bit）
00001000：RTC 月（低8bit）
00001001：RTC 年（低8bit）
00001010：DI7~0（低8bit）
00001011：DI15~8（低8bit）
00001100：DO7~0（低8bit；低有效，初始高=关闭）
00001101：DO15~8（低8bit；低有效，初始高=关闭）
00001110：AI0（16bit）
00001111：AI1（16bit）
00010000：AI2（16bit）
00010001：AI3（16bit）
00010010：AO0（16bit）
00010011：AO1（16bit）
00010100：AO2（16bit）
00010101：AO3（16bit）
00010110：本机 RF 地址（8bit，低8bit有效，存 EEPROM）
00010111：对端 RF 地址（8bit，低8bit有效，存 EEPROM）
00011000：收发模式（固定 0；统一异步主从，取消原 4 种模式）
00011001：主从位（8bit，存 EEPROM）
  0 = 从机：收到主站帧，按主站帧中的 CI₂（要求回传内容指示）回传本机数据
  1 = 主机：按发射表周期发帧（每帧含 CI₁ 本机内容 + CI₂ 要求从站回传），等从站回传，超时重传
00011010：UART1 485 波特率（16bit 数值，如 9600/19200/38400；存 EEPROM）
00011011：UART1 485 接收缓冲上限（1~127 字节；缓冲满即组帧发；存 EEPROM）
00011100：UART1 485 组帧超时（16bit，ms；距上次收字节超过则组帧发；存 EEPROM）
00011101：UART1 485 透传使能（0=关 1=开；存 EEPROM，默认 0=关）
00011110：保存配置命令（命令地址）
  写入：写 0x0001 触发"把当前配置表写入内部 EEPROM"，回状态码
    0x0001 = 保存成功
    0x0000 = 保存失败 / 未触发
  读取：回配置区有效性 0x0001 = 已保存且有效 / 0x0000 = 未保存或无效
  注：保存为阻塞操作（EEPROM 逐字节编程，约数百 ms），期间 UART3 收帧暂缓，
      上位机应等待回复后再发下一条；只读模式下本命令被拦截（自动转读）
00011111：恢复出厂命令（命令地址）
  写入：写 0x0001 触发"清除 EEPROM 配置区"（回 0x0001 = 成功）
  读取：回 0x0000
  注：清除后上电/下次恢复将使用固件默认配置；只读模式下同样被拦截
00100000~00111111：控制指令（调试用；写触发/读状态，默认 0）
  00100000（0x20）：RF 发送测试
    写 0x0001：发一帧遥测测试帧（内容 = 发送表[0]）；**回复 = 测试帧耗时 ms**
      （发送完成才回复，耗时用于评估最大更新率：周期 ≥ 往返=2×耗时 才留 0.5 余地）
    读：回 0
  00100001（0x21）：RF 接收计数
    读：回收到帧总数（16bit 回绕）
    写 0：清零
  00100010（0x22）：RF CRC 错计数
    读：回 CRC 错帧数
    写 0：清零
  00100011（0x23）：RF 发送溢出计数
    读：回发送溢出次数（发送忙拒绝新任务）
    写 0：清零
  00100100（0x24）：最近 RSSI
    读：回最近一帧 RSSI（有符号 dBm）
  00100101（0x25）：最近 SNR
    读：回最近一帧 SNR（有符号 dB）
  00100110（0x26）：频偏校正触发
    写 0x0001：触发一次频偏校正（仅当 0x28 校正开关=1 才执行，手动调试用）
    读：回校正状态 0=未校正 1=成功 2=失败 3=校正中
    注：仅手动触发，无自动校正；模式3 掉线重连走 RF 命令帧（见 frame.md）
        = 3s 无有效帧发探测命令(0x37+0x01) -> 从机回 ACK；5s 仍无则 SYS LED 报警
  00100111（0x27）：频偏校正值
    读：回校正后频率偏移（有符号 Hz，±32767Hz）
    写：手动设校正值（存 EEPROM，单位 Hz）
  00101000（0x28）：频偏校正开关
    写 0/1：0=关（默认，禁止自动/手动校正）/ 1=开（允许校正）
    读：回当前开关状态
  00101001（0x29）：应用 RF 配置（C 类参数立即生效）
    写 0x0001：重配 SX1278（RF 参数 0x30~0x38 立即生效，无需重启）
    读：回 0
  00101010（0x2A）：状态快照（长期稳定性/死机定位）
    写 0x0001：回标准写回复帧（数据=快照帧数 N），随后连发 N 个标准读帧
      （覆盖 RTC 0x03~0x09 + DI/DO/AI/AO + RF统计 0x21~0x25 + 内部状态 0x2B~0x2E）
    读：回 0；注：全为标准帧不破坏协议，N=28
  00101011（0x2B）：链路状态（只读内部状态；通联标志）
  00101100（0x2C）：RF 状态机（只读内部状态；0=待发 1=等回包）
  00101101（0x2D）：卡死位置码 dbgpos（只读；debug 构建写入，release 恒 0）
  00101110（0x2E）：485 接收缓冲长度（只读）
  00101111（0x2F）：射频调制（读写；0=LoRa 1=FSK；写后立即重配 SX1278）
  注：0x20~0x26 瞬时动作/状态不存 EEPROM；0x27/0x28 存 EEPROM；0x29/0x2A 瞬时；0x2B~0x2E 只读内部状态；0x2F 瞬时（写即重配芯片，不存）
00110000（0x30）：载波频率 低16bit（Hz，存 EEPROM）
00110001（0x31）：载波频率 高16bit（Hz，存 EEPROM；0x30/0x31 组 32bit）
00110010（0x32）：扩频因子 SF（6~12，存 EEPROM；空速自动算）
00110011（0x33）：带宽 BW（125/250/500 kHz，存 EEPROM）
00110100（0x34）：编码率 CR（5~8 = 4/5~4/8，存 EEPROM）
00110101（0x35）：发射功率 dBm（存 EEPROM）
00110110（0x36）：前导码长度（存 EEPROM）
00110111（0x37）：同步字（存 EEPROM）
00111000（0x38）：LNA 增益（存 EEPROM）
  注：0x30~0x38 为 RF 高层参数，上电时按此配置 SX1278（自动算寄存器）
01000000~01011111（0x40~0x5F）：CI₂[32] 从站回传内容指示
  地址 = 0x40 + 任务编号（0~31）
  值 = 主站第 N 个发射任务要求从站回传的内容指示（帧中 CI₂ 字段；存 EEPROM）
01100000~01111111：射频设置字段（调试用，SX1278 寄存器直写）
  低5位 = SX1278寄存器号（0x00~0x1F），值放低字节
00111001~00111110（0x39~0x3E）：FSK 关键寄存器直写（调试用）
  0x39→0x30 PACKETCONFIG1 · 0x3A→0x31 PACKETCONFIG2
  0x3B→0x32 PAYLOADLENGTH · 0x3C→0x33 NODEADRS
  0x3D→0x34 BROADCASTADRS · 0x3E→0x28 SYNCVALUE1
  (FSK 物理参数 BitRate/Fdev/RxBw 走 0x60~0x7F 直写 0x02~0x1F)
10000000~11111111：发射流程设置字段
  bit7 = 1
  bit6:2 = 任务编号（0~31）
  bit1:0 = 参数地址
  参数0（00）：发射内容 CI₁ = 帧内容指示字段（低字节；主站→从站传什么）
  参数1（01）：任务 ENA（bit0 = 1 启用，0 禁用）
  参数2（10）：执行周期 低16bit（小端序，单位= TIM4 6kHz 节拍 166.7us，6tick=1ms）
  参数3（11）：执行周期 高16bit（小端序，单位= TIM4 6kHz 节拍 166.7us，6tick=1ms）
  注：CI₂（要求从站回传）用独立地址 0x40~0x5F（见上）
## EEPROM 配置存储
内部数据 EEPROM（STM8S208MB 共 2KB，sduino EEPROM 库 idx 0~2047）中，配置区布局：
| 偏移 | 长度 | 内容 |
|------|:---:|------|
| 0 | 1 | 魔法数 0x5A |
| 1 | 1 | 版本 0x07 |
| 2 | 13 | 射频白名单寄存器值（见下） |
| 16 | 32 | 发射任务表：CONTENT[32]（CI₁） |
| 48 | 32 | 发射任务表：CI2[32]（要求从站回传内容指示） |
| 80 | 32 | 发射任务表：ENA[32] |
| 112 | 64 | 发射任务表：PERIOD_L[32]（小端序） |
| 176 | 64 | 发射任务表：PERIOD_H[32]（小端序） |
| 240 | 1 | 本机 RF 地址 |
| 241 | 1 | 对端 RF 地址 |
| 242 | 1 | 收发模式（固定 0） |
| 243 | 1 | 主从位（0x19） |
| 244 | 2 | 载波频率 低16（0x30，Hz 小端序） |
| 246 | 2 | 载波频率 高16（0x31，Hz 小端序） |
| 248 | 1 | SF（0x32） |
| 249 | 2 | BW（0x33，16bit，支持500kHz） |
| 251 | 1 | CR（0x34） |
| 252 | 1 | 发射功率（0x35） |
| 253 | 1 | 前导码（0x36） |
| 254 | 1 | 同步字（0x37） |
| 255 | 1 | LNA 增益（0x38） |
| 256 | 2 | 频偏校正值（0x27，有符号 Hz，小端序） |
| 258 | 1 | 频偏校正开关（0x28） |
| 259 | 2 | UART1 485 波特率（0x1A） |
| 261 | 1 | UART1 485 缓冲上限（0x1B） |
| 262 | 2 | UART1 485 组帧超时（0x1C） |
| 264 | 1 | UART1 485 透传使能（0x1D） |
| 265 | 1 | CRC-8（覆盖偏移 0~264） |
共 266 字节。
射频白名单（仅这些寄存器会被保存/恢复，避免存到只读/状态/FIFO 寄存器）：
  0x06/0x07/0x08 FRF 频率 · 0x09 PA_CONFIG 功率 · 0x0C LNA ·
  0x1D/0x1E/0x1F MODEM_CONFIG_1/2/3 · 0x20/0x21 前导码 ·
  0x22 PAYLOAD_LENGTH · 0x24 HOP_PERIOD · 0x39 SYNCWORD
上电恢复：setup 时读 EEPROM 校验通过则回填 SX1278（射频白名单）+ 发射任务表
  + 本机/对端地址 + 收发模式 + 频偏校正值/开关；校验失败或未保存则用固件默认值。
注：当前已实现"保存 / 恢复出厂 / 读取有效性"；"上电自动回填"随 RF 主循环接入启用。
